PORTAFOLIO WEB - JOSEPH HUAMAN HUANCA

Archivos:
- index.html: contenido del portafolio.
- styles.css: diseño adaptable a celulares y computadoras.
- script.js: menú móvil y año automático.

PUBLICAR EN GITHUB PAGES:
1. Crea un repositorio llamado CV en tu cuenta de GitHub.
2. Sube index.html, styles.css y script.js a la raíz del repositorio.
3. En el repositorio entra a Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Selecciona la rama main y la carpeta /(root), luego Save.
6. Espera la publicación. El enlace tendrá el formato:
   https://TU-USUARIO.github.io/CV/

PENDIENTE DE PERSONALIZAR:
- Agregar correo, LinkedIn y usuario real de GitHub.
- Confirmar fechas de formación y experiencia.
- Añadir enlaces o capturas reales de los proyectos.
- Revisar si todas las tecnologías listadas corresponden a tu nivel de dominio.

Nota: el contenido describe proyectos y prácticas académicas; no afirma que sean productos comerciales.
